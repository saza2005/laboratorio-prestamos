# laboratorio-prestamos

Sistema web de gestión de préstamos de laboratorio desarrollado con:

- Next.js App Router
- Supabase Auth
- PostgreSQL con RLS
- TypeScript
- TailwindCSS
- Server Actions

## Módulos principales

- Autenticación por roles
- Inventario
- Kardex / movimientos de inventario
- Solicitudes
- Solicitudes por grupos
- Préstamos
- Devoluciones
- Mantenimiento
- Dashboard
- Reportes Excel

## Roles

- admin
- lab_staff
- teacher
- student
