# FASE 6.3B-L1-F3AP - Project isolation invalid forensic audit

F3AP was local, read-only, and did not execute the target, coordinator or
inspector. F3AE through F3AO remain preserved exactly.

## Finding

`PROJECT_ISOLATION_INVALID` is returned by `checkProjectIsolation()` in
`scripts/e2e/verify-mutating-l1-single-process-preflight.mjs`. The function
reads three process environment inputs and first constructs a `URL` from
`NEXT_PUBLIC_SUPABASE_URL`. In the recorded F3AO launch, the process was
started without an environment-file loader, so the URL input was absent and
`new URL('')` threw. The catch branch returned `PROJECT_ISOLATION_INVALID`
before the expected project-ref or normal-project comparisons ran.

The coordinator increments no core counter before its gates pass. In F3AO,
`coordinatorReached=yes` means the harness called `runSingleProcessPreflight()`;
`targetCompleted=yes` means that promise returned a gate-failure result. It
does not mean observer startup, baseline, or a table read completed.
